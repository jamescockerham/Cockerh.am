# Contributing to Cockerh.am

No coding required. Contributions come in as GitHub issues.

1. Go to https://github.com/jamescockerham/Cockerh.am/issues/new/choose
2. Pick a template: add a person, share a photo, share a document, share DNA results, or report a correction.
3. Fill it in, including your source if you have one, and submit.

Issues are public, so please don't post private details about living people.
